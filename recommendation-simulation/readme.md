# 🎬 Recommendation System Simulator
## [live demo](https://projects-fxshxsmgmr7qhmf2zeijrx.streamlit.app/)
## Overview

This project is an interactive **Recommendation System Simulator** built using **Python** and **Streamlit** to help users understand how different recommendation algorithms work in real-world applications such as Netflix, Amazon, Spotify, and YouTube.

The application demonstrates and compares four major recommendation approaches:

* 📊 Demographic Filtering
* 👥 Collaborative Filtering
* 🎯 Content-Based Filtering
* 🔄 Hybrid Recommendation System

The project uses the **MovieLens 100K (ML-100K)** dataset and provides both practical recommendations and educational explanations of each recommendation technique.

---

## 🚀 Features
## [live demo](https://projects-fxshxsmgmr7qhmf2zeijrx.streamlit.app/)

### 📊 Demographic Filtering

* Recommends popular movies based on overall user ratings.
* Demonstrates how recommendations can be generated using community trends and demographic preferences.

### 👥 Collaborative Filtering

* Finds users with similar interests.
* Generates recommendations based on the behavior and ratings of similar users.

### 🎯 Content-Based Filtering

* Recommends movies similar to those liked by the user.
* Uses movie attributes and user preferences to create personalized suggestions.

### 🔄 Hybrid Recommendation System

* Combines collaborative and content-based approaches.
* Produces more accurate and balanced recommendations by leveraging the strengths of multiple algorithms.

### 📚 Learn Mode

To make the project educational, every recommendation technique includes a dedicated **Learn Section** that explains:

* How the algorithm works
* Real-world use cases
* Advantages and limitations
* Recommendation generation process

This allows users to not only receive recommendations but also understand the underlying concepts behind recommendation systems.

---

## 🛠️ Tech Stack

* Python
* Streamlit
* Pandas
* NumPy
* Scikit-learn
* MovieLens 100K Dataset

---

## 🎯 Project Goal

The primary goal of this project is to provide a hands-on learning experience for understanding recommendation systems. Rather than focusing only on recommendations, the application visually demonstrates the logic behind different recommendation techniques, making it useful for students, beginners, and machine learning enthusiasts.
