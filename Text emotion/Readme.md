## 📄 Abstract

Emotion classification from text has become an increasingly important task in natural language processing with applications in sentiment analysis, social media monitoring, and human-computer interaction. In this project, a multi-class emotion classification model was developed to classify Twitter messages into six emotion categories: sadness, joy, love, anger, fear, and surprise. Multiple traditional machine learning approaches were evaluated, including Naive Bayes, Logistic Regression, Support Vector Machines (SVM), and Random Forest, using various feature extraction techniques such as Bag-of-Words (BoW), TF-IDF, and Word2Vec. Ensemble methods including Gradient Boosting, XGBoost, LightGBM, and CatBoost were also explored. The best-performing model, **Logistic Regression with TF-IDF features**, achieved approximately **92.2% accuracy** and an **F1-score of 92.1%**, demonstrating the effectiveness of traditional machine learning approaches for text-based emotion classification tasks.

## 🎯 Project Overview

This project develops a **multi-class emotion classification system** for Twitter messages using traditional machine learning approaches. The model classifies text into six emotion categories:

| Label | Emotion |
|-------|---------|
| 0     | Sadness |
| 1     | Joy     |
| 2     | Love    |
| 3     | Anger   |
| 4     | Fear    |
| 5     | Surprise|

The **Logistic Regression model with TF-IDF features** achieved an impressive **92.2% accuracy** and **92.1% F1-score**, demonstrating the effectiveness of traditional ML approaches for text-based emotion classification.

---

## 📌 Problem Statement

Develop a multi-class text classification model that can accurately classify Twitter messages into one of six emotion categories while maintaining high classification accuracy across all emotions.

---

## 🎯 Objectives

- Build a multi-class emotion classifier using traditional machine learning approaches.
- Preprocess and clean the text data for optimal feature extraction.
- Implement multiple feature extraction techniques (BoW, TF-IDF, Word2Vec).
- Evaluate multiple classification algorithms (Naive Bayes, Logistic Regression, SVM, Random Forest, and Ensemble methods).
- Perform hyperparameter tuning to optimize model performance.
- Compare model performance using accuracy and F1-score metrics.
- Identify the best-performing model for emotion classification.
